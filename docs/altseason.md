2026-11-15 🗄️データ基盤 記録。既製の指数の過去分は無料では取れないため、利用者の了承を得て**自前で計算している**（下の「自前の計算」）。

## 既製の指数の過去の履歴
| 取得元 | 計算方法 | 過去の履歴 | 結果 |
| --- | --- | --- | --- |
| Blockchaincenter（元祖） | 時価総額の上位50（ステーブルコイン・ラップトークン除く）のうち、直近90日でBTCより上がった割合（75以上でアルト期） | 公開のAPIなし（サイトのグラフのみ） | 取れない |

結論：**既製の指数の過去の履歴は、無料・キーなしでは取れない**。推測で埋めることはしない。

## 自前の計算（2026-11-15 稼働。fetchers/altseason.py、ワークフロー altseason：毎日09:40 JST）
- 材料：Binance 公式一括データ（data.binance.vision）の USDT 建て現物の日足（上場廃止の銘柄の過去分も残っているので、今残っている銘柄だけで計算する偏りを減らせる）。
- 対象：その日に取引されている USDT 建ての銘柄から、ステーブルコイン・レバレッジトークン・ラップトークン・BTC を除き、直近30日の売買代金の上位50（時価総額の履歴は無料で取れないため、売買代金で代用）。90日以上の価格がある銘柄だけ。
- 値：上位50のうち、直近90日の騰落率がBTCを上回った割合（0〜100）。
- 既製の指数との違い：時価総額ではなく売買代金で選ぶ、Binance に上場している銘柄だけ。値は既製の指数と一致しない（名前は「季節指数（自前・Binance売買代金上位50）」として区別する）。
- 費用：取得は GitHub Actions（公開リポジトリのため分数の制限なし）。Google Cloud は使わない。初回は数百銘柄 × 月次ファイルの取得が必要で、時間を測ってから区切って実行する。

### 実装の内容
- 銘柄の一覧は data.binance.vision の S3 の一覧（上場廃止を含む USDT 建て現物、11/15時点で700銘柄）。除外：ステーブルコイン・法定通貨・金（PAXG・XAUT）・ラップトークン（WBTC・WBETH など）・レバレッジトークン（BTCUP・BNBBULL など）。
- 加工前の値（終値・売買代金）：data/raw/universe/YYYY-MM.csv（月ごと）。過去は月次ファイル、直近60日は data-api.binance.vision。
- 出力：data/raw/sentiment/altseason.csv（date, value, n_coins, n_beat, btc_ret_90d_pct, source, fetched_at）。当日（途中）は計算しない。対象が20銘柄未満の日は空欄（値が出るのは 2019-04-18 から。2019年は対象が50に満たない日がある → n_coins を見る）。
- 最新日の上位50の内訳：data/clean/altseason_members_latest.csv。

### 注意
- 名前の変更・単位の変更（デノミ）があった銘柄は、90日騰落率がおかしな値になることがある。
- 売買代金で選ぶため、短期的に売買が急増した銘柄が入りやすい。
