# アルトコイン季節指数：取得元の確認結果（追補 第18章 ③）

2026-11-15 🗄️データ基盤 記録。**現時点では data/raw/sentiment/altseason.csv は作っていない**（下の理由）。

## 既製の指数の過去の履歴
| 取得元 | 計算方法 | 過去の履歴 | 結果 |
| --- | --- | --- | --- |
| Blockchaincenter（元祖） | 時価総額の上位50（ステーブルコイン・ラップトークン除く）のうち、直近90日でBTCより上がった割合（75以上でアルト期） | 公開のAPIなし（サイトのグラフのみ） | 取れない |
| CoinMarketCap | 上位100の90日騰落率 | `/v1/altcoin-season-index/historical` がある（Pro APIのキーが必要）。無料プランで使えるかは未確認 | キーなしでは取れない |
| CoinGlass | 不明 | APIは Startup 以上の有料プランのみ（Hobbyist は対象外） | 取れない |

結論：**既製の指数の過去の履歴は、無料・キーなしでは取れない**。推測で埋めることはしない。

## 自前で計算する案（未着手・利用者の判断待ち）
- 材料：Binance 公式一括データ（data.binance.vision）の USDT 建て現物の日足（上場廃止の銘柄の過去分も残っているので、今残っている銘柄だけで計算する偏りを減らせる）。
- 対象：その日に取引されている USDT 建ての銘柄から、ステーブルコイン・レバレッジトークン・ラップトークン・BTC を除き、直近30日の売買代金の上位50（時価総額の履歴は無料で取れないため、売買代金で代用）。90日以上の価格がある銘柄だけ。
- 値：上位50のうち、直近90日の騰落率がBTCを上回った割合（0〜100）。
- 既製の指数との違い：時価総額ではなく売買代金で選ぶ、Binance に上場している銘柄だけ。値は既製の指数と一致しない（名前は「季節指数（自前・Binance売買代金上位50）」として区別する）。
- 費用：取得は GitHub Actions（公開リポジトリのため分数の制限なし）。Google Cloud は使わない。初回は数百銘柄 × 月次ファイルの取得が必要で、時間を測ってから区切って実行する。
